# Контракты XRONIX

Единственный источник правды о том, как общаются части системы. Все работают на моках по этим файлам и не ждут друг друга.

| Файл | Между кем |
|---|---|
| [api.md](api.md) | Frontend ↔ Backend (REST, JWT) |
| [conveyor.md](conveyor.md) | **v2.** Frontend ↔ Backend: компании, подбор, заявки, лента, рабочее место аналитика |
| [integrations.md](integrations.md) | **v2.** Backend ↔ integrations-mock (ЕГРЮЛ/ЕГРИП, ФНС, БКИ) |
| [ai.md](ai.md) | Backend ↔ AI-сервис (v2: своя модель — `/ai/consult` для чата подбора бизнеса, `/ai/parse-need` для мастера) |
| [templates.md](templates.md) | **v2.** Расчёт проекта без ИИ: шаблоны сфер [`templates/spheres.v1.json`](templates/spheres.v1.json) и формулы |
| [products.demo.json](products.demo.json) | **v2.** Демо-продукт «Старт» для нового бизнеса (не продукт Альфа-Банка) |
| [dictionaries.json](dictionaries.json) | **v2.** Коды и тексты: цели, сферы, статусы, причины отказа |
| [rules/credit_rules.v1.json](rules/credit_rules.v1.json) | **v2.** Правила скоринга и решения |
| `schemas/*.json` | JSON Schema (draft-07) для всех тел запросов и ответов |
| `examples/*.json` | Примеры, которые проходят проверку по схемам |

## Правила
1. Меняет контракты только капитан (Александр). Нужна правка — пишешь в чат команды, правим здесь, потом подстраиваются все.
2. Любое изменение: схема, пример и `.md` меняются в одном коммите, затем `npm run check`.
3. Поле нельзя переименовать или сменить его тип молча. Новое поле добавляем как необязательное, ломающее изменение повышает `CONTRACT_VERSION`.
4. Деньги: целые числа в рублях, без пробелов и строк. Проценты: числа. Даты: ISO 8601 в UTC.

`CONTRACT_VERSION`: **2** (конвейер v2, логика — [docs/CONVEYOR.md](../docs/CONVEYOR.md))

## Проверка
```
cd contracts
npm install
npm run check
```
Скрипт проверяет, что все примеры проходят схемы, справочники совпадают с перечислениями в схемах, ИНН и ОГРН проходят контрольные суммы, график платежей сходится с аннуитетом, и прогоняет смысловые правила плана (разделы «Правила плана» в [ai.md](ai.md)). Бэкенд может взять функцию `checkPlan` из `check.mjs` как образец своей проверки.
