# Контракты XRONIX

Единственный источник правды о том, как общаются части системы. Все работают на моках по этим файлам и не ждут друг друга.

| Файл | Между кем |
|---|---|
| [api.md](api.md) | Frontend ↔ Backend (REST, JWT) |
| [ai.md](ai.md) | Backend ↔ AI-сервис |
| `schemas/*.json` | JSON Schema (draft-07) для всех тел запросов и ответов |
| `examples/*.json` | Примеры, которые проходят проверку по схемам |

## Правила
1. Меняет контракты только капитан (Александр). Нужна правка — пишешь в чат команды, правим здесь, потом подстраиваются все.
2. Любое изменение: схема, пример и `.md` меняются в одном коммите, затем `npm run check`.
3. Поле нельзя переименовать или сменить его тип молча. Новое поле добавляем как необязательное, ломающее изменение повышает `CONTRACT_VERSION`.
4. Деньги: целые числа в рублях, без пробелов и строк. Проценты: числа. Даты: ISO 8601 в UTC.

`CONTRACT_VERSION`: **1**

## Проверка
```
cd contracts
npm install
npm run check
```
Скрипт проверяет, что все примеры проходят схемы, и прогоняет смысловые правила плана (разделы «Правила плана» в [ai.md](ai.md)). Бэкенд может взять функцию `checkPlan` из `check.mjs` как образец своей проверки.
