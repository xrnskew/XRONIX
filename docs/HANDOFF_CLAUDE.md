```sh

git merge-base --is-ancestor origin/dev HEAD && git merge-base --is-ancestor origin/backend HEAD && git merge-base --is-ancestor origin/frontend HEAD \

Параллельный запуск для `dev` GitHub сам отменяет как дубль. Статус смотреть через `mcp__github__actions_list` (`list_workflow_runs` с `resource_id: deploy-frontend.yml`).

## 9. Подводные камни (наступали, не повторять)

- **Tailwind v4:** `space-y-*` ставит `margin-bottom`, а не `margin-top`; неслойные стили из `index.css` (`.tint`, `.card-ring`) сильнее утилит; правило `.wide-grid > .stack > .card-ring` перекрывает фон `.tint` на широком экране (остаётся рамка).
- **`innerText` применяет `text-transform`:** заголовки вида `uppercase` возвращаются заглавными, в проверках искать без учёта регистра.
- **`rub()` и числа форматируются с неразрывным пробелом** (` `), в регулярках использовать `\s`.
- **PlanRoute** (`src/phone/PlanRoute.tsx`): URL `?plan=` главнее контекста. После смены плана сначала менять URL, иначе план откатится; страница при загрузке нового плана перерисовывается целиком, состояние компонентов теряется, сообщения передавать через `location.state` (как баннер «План пересчитан» на «Финансах»).
- **Прогресс мастера заявки** лежит в `sessionStorage` на час и включает `usedPlan`: при добавлении состояния в мастер сохранять его в `Progress`, иначе шаги съедут после «Назад».
- **Причины отказа от продуктов приходят строками**, `creditReasons.ts` разбирает их регулярками: при изменении текстов в `creditRules.ts` и в backend (`credit_rules.py`) обновлять классификатор и тесты.
- **Пересчёт плана** (`replan.ts`) восстанавливает вводные: сфера по названию плана, ответы анкеты из сообщений чата, остальное по умолчанию. Если ответ не сохранился, стоимость запуска может чуть отличаться. Саше нужно сверить на реальном плане.
- **Моки против продакшена:** на моках токен не сохраняется (перезагрузка возвращает на вход), данные общие для любого пользователя, пустые состояния через интерфейс не достать. Возврат последнего чата после перезагрузки проверяется только на живом сайте.
- **Деплой:** жду-проверка по строке в сборке ненадёжна (код в отдельных модулях), смотреть статус запуска Actions.
- Контракты и `backend/` читают файлы шаблонов при старте: при их правке backend надо перезапускать (это делает Илья).
