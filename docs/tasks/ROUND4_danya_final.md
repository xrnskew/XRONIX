## 1. «Без сотрудников» → `staff = 0` (обязательно)
Контракт теперь разрешает 0 сотрудников (`min: 0` в шаблонах). В анкете AI сейчас не распознаёт такие ответы.
- В ответе на вопрос «Сколько сотрудников?»: «0», «ноль», «без сотрудников», «никого», «работаю сам», «я один», «сам», «сама» → `answers.staff = 0`. Для сфер, где вопрос называется иначе (мастера, продавцы), то же правило.
- В свободной фразе («хочу пекарню, работать буду сам») → `staff = 0` только когда это явно про сотрудников; не путать с «сам себе хозяин», «я сам решу» без слов про работу.
- Негативные: «нет» без контекста на вопрос о сотрудниках не должно становиться 0, если вопрос был про другое; «2 сотрудника», «двое» → 2.
- Тесты: не меньше 8 позитивных и 4 негативных формулировок в ручном наборе, плюс регрессия на правило 9 (опыт не должен путаться).

## 2. Ответ на «не знаю» и «хочу что-то прибыльное» (обязательно)
Сейчас при такой фразе чат повторяет вопрос «Что открываем? Кофейня, Пекарня, …» (скриншот из бета-теста: три ответа подряд повторяют одно и то же).
- Первый раз — те же варианты, но с коротким живым ответом: «Давайте подберём вместе. Могу посчитать кофейню, пекарню, автомойку, магазин одежды, салон красоты или пункт выдачи. Что ближе: общепит, услуги или торговля?»
- Второй раз подряд — конкретное предложение с примером из базы знаний: «Например, пекарня в вашем городе: …» (используй город из `state`, если он есть, и один факт из базы; суммы и прибыль не называть).
- Третий раз — вежливо предложить выбрать кнопкой одну из шести сфер.
- Не больше 600 символов, числа только из базы, без придуманных сумм.
- Тесты: серия из 3 реплик «не знаю», «что-то прибыльное», «посоветуйте» даёт три разных ответа без повтора вопроса слово в слово.
