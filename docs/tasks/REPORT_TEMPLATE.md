# Макет отчёта по раунду

Копируйте этот файл в `docs/reports/ROUND<N>_<команда>.md` (например `ROUND2_backend.md`), заполняйте и коммитьте в своей ветке. Саше присылайте ссылку на коммит с отчётом. Один отчёт на команду: бэкенд — один общий от Ильи, включая часть Дани.

Правила:
- Каждый пункт задачи — строка в таблице «Задачи». Номера — как в файле задач раунда.
- Статус только один из трёх: **готово**, **частично**, **нет**. «Частично» и «нет» — всегда с причиной.
- «Как проверить» — команды или шаги, которые проверяющий повторит без вопросов. С ожидаемым результатом.
- Отступления от контрактов — отдельным разделом, даже мелкие. Без них отчёт не принимается.
- Тесты — реальные цифры из вывода, а не «всё прошло».
