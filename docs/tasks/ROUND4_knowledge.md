# Даня: расширить базу знаний о рынке (открытые данные)

Зачем: чат отвечает по числам из `ai/app/rules/data/knowledge.cities.json` (заведения OSM, зарплата Росстата, население). Хотим, чтобы совет звучал как после изучения рынка: конкуренция, спрос, налоги, поддержка, срок жизни бизнеса. Работаем по тому же конвейеру: `ai/knowledge/collect_*.py` → `raw/` → `build.py` → `knowledge.cities.json`. Отчёт Дани идёт Илье.

## Правила
- Факты только из открытых источников, с датой и ссылкой. GigaChat факты не генерирует, только перефразирует тексты (как в `THIRD_PARTY_NOTICES.md`, раздел 7).
- В ответах чата числа подаём как «около N по данным <источник>». Нет данных по городу или региону: фразу не выдумываем, пропускаем.
- Перед сбором проверить лицензию и условия использования каждого источника, записать в `THIRD_PARTY_NOTICES.md` (раздел 5) и `ai/LICENSES.md`. Сомнительный источник не берём и пишем Илье.
- Сырые ответы кладём в `raw/`, чтобы сборка воспроизводилась. Скрипты не должны падать без сети: если файл уже есть, берут его.
- Схема `contracts/schemas/knowledge.schema.json` и `npm run check` в `contracts/` остаются зелёными. Новые поля необязательные.

## Что собрать (по убыванию пользы; доступность и лицензии проверить самому)
1. **Конкуренция шире.** OSM: ещё сферы (парикмахерские, шиномонтаж, фитнес, аптеки, детские центры, химчистки, цветы, зоомагазины), плотность на 10 тыс. жителей, сравнение с медианой по городам-миллионникам.
2. **Реестр МСП ФНС** (открытые данные ФНС): число малых компаний и ИП по ОКВЭД и региону. Если есть ЕГРЮЛ-статистика регистраций и ликвидаций, считаем долю закрывшихся за 3 года по сфере (фраза «около N% таких бизнесов закрываются за три года»).
3. **Росстат / ЕМИСС:** доходы населения по региону, оборот розницы и общепита на душу, цены на типовые товары (для проверки средних чеков в шаблонах).
4. **Налоги:** региональные ставки УСН и патента, налог для самозанятых (НПД): какие режимы доступны для сферы. Только факты с датой закона.
5. **Поддержка малого бизнеса:** «Мой бизнес» (МСП.РФ), льготные программы, гранты на старт, соцконтракт: что доступно в регионе, суммы, условия, ссылка. Дата снимка обязательна.
6. **Разрешения по сферам:** какие лицензии, СЭС, ККТ и уведомления нужны (общепит, красота, пункт выдачи и т. д.), со ссылкой на закон или официальную страницу. Короткий список по 3–5 пунктов на сферу.

Аренду не парсим: открытых данных нет. Если нужна, помечаем оценку шаблонов и прямо говорим об этом.

## Как использовать в чате
- Новые факты ложатся в те же слоты, что и сейчас (`{venues}`, `{in_city}` и т. д.), плюс 2–3 новых: налог, поддержка, срок жизни.
- В плане (`plan.risks` или заметка) показывать не больше одного нового факта на блок, чтобы текст не разрастался.
- В диалоге факт упоминается, когда он есть для этой сферы и города. Без данных ответ остаётся прежним.

## Готово, когда
- `collect_*` и `build.py` воспроизводят данные из `raw/`, тесты `ai` зелёные, метрики на dev-наборе не просели (до и после, одной таблицей).
- Покрытие: сколько городов и сфер получили каждый новый факт. Если меньше 80% по крупным городам, отметить в отчёте.
- Пример «было / стало» для 3 разных сфер.
- Источники и лицензии внесены в `THIRD_PARTY_NOTICES.md`.
- Отчёт Ильи в формате `docs/tasks/REPORT_TEMPLATE.md`.
