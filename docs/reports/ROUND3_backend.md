### Запуск для проверки

```sh
git clone --branch backend https://github.com/xrnskew/XRONIX.git
cd XRONIX
docker compose up -d --build --wait --wait-timeout 180
# http://localhost:8080/app — кнопки двух демо-входов; /docs — OpenAPI
cd contracts
npm ci
npm run check
cd collection
bru run --env local --env-var baseUrl=http://localhost:8080 --delay 1000 --bail
```

Bruno 4.2.1 установить отдельно (`npm install -g @usebruno/cli@4.2.1`); окружение local в репозитории использует 127.0.0.1:18000, поэтому для compose выше явно указан localhost:8080. Полный изменяющий сценарий запускать на свежей тестовой БД, не повторять на production. Остановка только тестового ai: `docker compose stop ai`; новый чат обязан дойти до запасного плана; вернуть `docker compose up -d ai --wait`.
