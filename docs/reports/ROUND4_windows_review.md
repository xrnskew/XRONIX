## Дефект 900000 → 0 ₽: воспроизведён и исправлен в backend

Это ошибка передачи контекста, не особенность Windows. В новом чате «Хочу открыть пекарню в Самаре» неизменённый AI @311e860 задаёт вопрос:

> Для открытия бизнеса собственными средствами располагаете какой суммой? Если своих нет, напишите «нет».

Backend включал **весь вопрос вместе с ответом 900000** в новое пользовательское message. Для некоторых вариантов вопроса AI не выделял строку ответа и трактовал «своих нет» из подсказки как пользовательский факт. После следующей реплики «Не знаю, посчитайте по умолчанию» создавался план с own_funds_rub=0.

Исправление — **`ce54a67`**. В `backend/app/consult.py` для структурированного `question_id=own_funds` теперь используется однозначная подпись «Сколько своих денег готовы вложить?» и буквальный ответ пользователя. Подсказка с условным «нет» остаётся в исходном вопросе/истории, но не переносится в новое пользовательское сообщение. Формат API, AI-код, frontend и остальные вопросы не менялись. Профиль не нужно заполнять для обхода ошибки.

Проверка через настоящие backend-маршруты, MockTransport и неизменённые ASGI-маршруты архивного AI @311e860 на отдельных временных SQLite:

| Сценарий | До исправления | После исправления |
|---|---:|---:|
| Структурированный ответ 900000, затем готовый план | **0 ₽** | **900000 ₽** |
| Статусы трёх запросов backend | 200/200/200 | 200/200/200 |

Полные переданные в AI запросы и ответы: [до](artifacts/ROUND4_structured_funds_before.json), [после](artifacts/ROUND4_structured_funds_after.json). Это регрессия интеграции, не пересчёт независимой оценки AI и не повторный Windows/Docker-прогон.

Добавлены 9 HTTP-регрессий: три формулировки вопроса × ответы `900000`, `0`, `нет`. Проверяются сохранение вопроса в UI/истории, отсутствие условной подсказки в текущем сообщении AI, сохранение ответа и сумма готового плана. До правки первый тест падал; после правки целевой набор с регрессиями ROUND3 — **55 passed за 34,71 с**. Команда:

```sh
PYTHONPATH=backend backend/.venv/bin/python -m pytest -q backend/tests/test_structured_funds.py backend/tests/test_round3.py --disable-warnings --tb=short
```

Полный backend-прогон после исправления: **328 passed, 1583 warnings, 178,15 с**, exit 0. Команда: `PYTHONPATH=backend backend/.venv/bin/python -m pytest -q backend/tests --disable-warnings --tb=short`. [Вывод](artifacts/ROUND4_structured_funds_pytest.txt). Предупреждения относятся к устаревающим API зависимостей, а не падениям тестов. 22 октября после отдельного разрешения Ильи production-backend обновлён до 01bbb4b с этой правкой; HTTPS smoke успешен. Текущая production-конфигурация использует запасной диалог без AI, поэтому сам воспроизведённый AI-путь там не активен.

## Точечная перепроверка на Windows

После получения исправленного backend-коммита пересобрать тестовый backend, сохранив том. Войти пользователем с незаданным бюджетом, создать **новый** чат, написать «Хочу открыть пекарню в Самаре», в поле вопроса о своих средствах ввести `900000`, затем завершить вопросы анкеты. Убедиться, что в плане 900000 ₽ своих средств, а при выборе будущего ИП и поручителя доступен Старт. Записать SHA и результат, по возможности сохранить штатный скриншот. Это повторная сборка с кэшем; её время не заменяет исходный cold build.
