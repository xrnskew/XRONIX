### Что пошло не так

Неудачные попытки записаны, ничего не стёрто.

1. **Docker на машине не было.** Установка Docker Desktop 4.96.2 «для пользователя» упала: нет компонента Windows «Virtual Machine Platform», а без прав администратора его не включить. Повторная установка; затем Docker Desktop сообщил «WSL not installed» — WSL 3.0.3 поставлен командой `wsl --install --no-distribution` от администратора, перезагрузка. В замер не входит (п. 3 условий задачи), но первому запуску на «чистой» Windows это стоит учесть в README.
2. **Попытка 1 скрипта замера не стартовала** (`attempt1-script-parse-error.txt`): Windows PowerShell 5.1 прочитал `.ps1` без BOM как ANSI, русская строка в скрипте сломала разбор. Клон и сборка не выполнялись, Docker остался пустым. Скрипт переписан только латиницей (`run-measure.ps1` — попытка 2, по ней все числа).
3. **Отличия от команд задачи** (на числа не влияют):
   - вывод `docker compose up` сохранён в `up-log.txt` (внутри `Measure-Command` он иначе теряется);
   - `stop-ai-log.txt`, `start-ai-log.txt`, `ps-final.txt`, `timing-ai-restart.txt` — сверх задачи; «дождаться healthy» сделано через `docker compose start ai && docker compose up -d --wait --wait-timeout 300`;
   - строки `docker : … NativeCommandError` / `RemoteException` в логах — не ошибки: Docker пишет ход сборки в stderr, PowerShell 5.1 оборачивает такие строки. В `up-log.txt` три предупреждения pip «Running pip as the 'root' user» — штатные для сборки образа, не ошибки.
4. **Сеть.** Ранее в тот же вечер запросы к внешним серверам то обрывались, то шли по 10–30 с. Во время замера (`clone` 5 с) сбоев не было, но время `up` с загрузкой образов от сети зависит.
5. **Наблюдения в приложении** (не правили — это `backend/` и `frontend/`, для Саши):
   - запасной диалог без AI на «Хочу кофейню в Казани, 500 000 ₽» спросил свои деньги ещё раз — сумма без слова «своих» им не распознаётся;
   - при остановленном `ai` в шапке чата по-прежнему «ИИ-консультант · на связи».
