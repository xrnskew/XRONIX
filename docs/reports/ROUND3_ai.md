### Сквозная проверка с бэкендом (HTTP, без браузера)

Бэкенд из `dev` @ `8fd34fb` (`MOCK_AI=false`, `CONSULT_CHAT=true`, отдельная SQLite) + сервис `ai` из этой ветки, вход `client@xronix.demo`, `POST /api/chats/{id}/messages`:

Факт о конкуренции второй раз не звучит.
- Второй чат «Привет! Думаю про пекарню в Самаре, есть 900 тыс» — те же факты, другие формулировки.
- **Уточнение после приёмки (замечание Саши):** вариант выбирается по хешу первого сообщения человека и номера реплики, id чата в запросе `/ai/consult` нет. Поэтому чаты с одинаковым первым сообщением («Хочу открыть пекарню в Самаре» четыре раза) получают одинаковые ответы; формулировки различаются только между чатами, которые начинаются по-разному. Решили так и оставить: живые люди и жюри пишут по-разному.
- Сервис `ai` остановлен → бэкенд ведёт запасной диалог и сразу считает план «Пекарня, Самара».
- Healthcheck из `docker-compose.yml` бьёт в `/ai/health` — метод на месте, отвечает `{"status": "ok"}`.
