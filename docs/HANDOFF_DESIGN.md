# Передача: состояние проекта XRONIX и дизайн (22 октября 2026)

Документ для новой сессии, которая будет улучшать дизайн. Дедлайн хакатона «Альфа-Будущее» (кейс «Умный кредитный кабинет предпринимателя») — 26 октября 2026.

## Что готово
- **Кабинет клиента (frontend):** чат подбора бизнеса с AI → план (смета, прогноз, риски, налоги, чип опыта) → финансы и калькулятор кредита → мастер заявки (три пути, подсказки «что изменить», прогресс сохраняется при «назад») → заявка с лентой статусов, принятие условий, подписание, выдача → лента событий, профиль.
- **Рабочее место аналитика:** очередь с фильтрами, карточка заявки, решения (одобрить, встречные условия, запрос данных, отказ), сводка.
- **Вход:** «Новый пользователь» и «Войти» крупно, «Клиент» и «Аналитик банка» — тестовые роли с плашкой «тест».
- **Backend (FastAPI + SQLite), `integrations-mock`, сервис `ai` (система правил, без нейросети), контракты (JSON Schema, примеры, `npm run check`).** На production: `api.xronix.ru`, сайт `xronix.ru` на настоящем API (GitHub Pages, `VITE_USE_MOCKS=false`).
- **План и расчёт:** зарплаты от средней по региону (Росстат, 100 городов), аренда со ставкой города, налоговая справка (УСН, МРОТ), опыт спрашивается в чате для каждого бизнеса, ноль сотрудников.
- **Качество чата:** 0,98–1,00 на наших наборах; 77% (37 из 48) на независимом синтетическом наборе из внешнего ИИ (`docs/reports/ROUND4_eval_result.md`).
- **Продукты:** в интерфейсе везде «продукт XRONIX (демо)», название банка и ссылки на него в интерфейсе не показываются.

## Дизайн: карта
- **Стек:** React 19, Vite, TypeScript, Tailwind v4 (токены в `src/index.css`, блок `@theme`), HashRouter, графики через lazy recharts.
- **Тёмный кабинет, красный акцент.** Токены: `bg #0e0e10`, `surface #19191c`, `surface-2 #232327`, `surface-3 #2d2d33`, `line #2c2c31`, `text #f5f5f6`, `muted #8d8d95`, `accent #ff4538`, `accent-soft #ff8a80`, `ok #3ddc84`, `warn #ffb020`, `steel #93a6c8` (ход банка), кнопки `fill #e02a1e` (белый текст). Шрифты: Onest (текст), Unbounded (заголовки и цифры). Презентация (лендинг) светлая: `paper`, `ink`, `brand`.
- **Смысл цветов (недавно уточнён):** зелёный — хорошая новость (одобрено, выдано), жёлтый — нужны ваши данные или решение, красный — отказ или главное действие, стальной — работает банк, серый — закрыто. Функция `statusTone` в `src/phone/conveyor/parts.tsx`.
- **Компоненты:** `src/phone/ui.tsx` (Badge, Card, Screen, Button, Chip, Stat, SectionTitle, Wide/Conveyor-контексты), `parts.tsx` (StatusBadge, MoneyInput, Steps, whoseMove), `conveyor/Track.tsx` (лента этапов с анимацией «конвейер»), мастер `conveyor/wizard/*`, экраны `phone/screens/*`, аналитик `app/bank/*`, лендинг `landing/*`.
- **Анимации:** классы `rise`, `appear`, `fill-in`, `pop`, `belt`, `node-pulse` в `index.css`; счётчики `useCountUp`; все отключаются при `prefers-reduced-motion`.
- **Адаптив:** десктоп ≥ 1024 (боковое меню), телефон ≤ 390 (нижнее меню). Проверять обе ширины.

## Идеи на дизайн-круг (не сделаны)
1. Чат: ответы анкеты показывать компактными тегами («Опыт: нет опыта»), а не повторять вопрос в красном пузыре (сейчас история с сервера хранит исходный текст, нужна отдельная отрисовка).
2. Карточка «План готов» в чате: крупнее, с цветом окупаемости и мини-диаграммой структуры сметы.
3. Анимация появления карточек в списках (заявки, продукты, лента) со ступенчатой задержкой.
4. Пустые состояния (нет заявок, нет планов) с иллюстрацией и главным действием.
5. Лендинг: проверить слайды на телефоне после смены текстов («Кредитные продукты XRONIX», «ИИ спрашивает про каждый бизнес отдельно»).
6. Аналитик: акцентные цвета в карточке заявки (класс скоринга, причины, стоп-факторы) и анимация решения.
7. Доступность: контраст `muted` на `surface-2`, фокус-кольца, подписи у иконок.
