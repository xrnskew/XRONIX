## Готовое следующее задание Дане

Даня, e3e2688 принят и собран в backend, замечания первого ревью закрыты. Следующая цель —
честная проверка правил на новых фразах, потому что прежний holdout использовался при настройке.
Работай только в backend-ai и ai/, бэкенд/фронт/контракты не меняй; обучение и внешние API не нужны.

1. Зафиксируй версию правил e3e2688 для оценки. Подготовь новый ручной набор 50–100 запросов
   вне банков генератора: разговорные фразы, исправления, отрицания, несколько сумм с разным
   смыслом (свои/кредит/чек), похожие города, неизвестный бизнес, короткие ответы на анкету,
   смена роли и запросы не про бизнес. По возможности используй фразы команды, переданные
   через Илью; не называй собственные шаблоны независимыми пользовательскими данными.
2. Разметь по действующим схемам. Для consult сохраняй весь видимый контекст: текст,
   вопросы и варианты; никаких скрытых подсказок в эталоне. Схемы и смысловые проверки обязательны.
3. Сохрани первый результат оценки неизменённых правил ДО любых исправлений.
   Если дорабатываешь правила по ошибкам, этот набор становится development-набором:
   не называй его новым независимым holdout и не подменяй исходные метрики.
4. Отдельно укажи точность по полям, type/state целиком, придуманные суммы и обещания,
   время mean/p95, число запросов, 10 характерных ошибок и ограничения.
5. Уточни в документации, что текущий сервис — собственная система правил/шаблонов,
   а исторический выбор Qwen/обучение не является текущей реализацией.

Ожидаемый результат: коммит backend-ai, новый набор с происхождением и разметкой,
