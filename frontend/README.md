# Frontend

React + Vite + TypeScript + Tailwind v4 + react-router + Recharts. Контракты: [`/contracts`](../contracts).

```
cd frontend
npm install
npm run dev      # http://localhost:5173
npm run build
```

## Режимы
- `VITE_USE_MOCKS=true` (по умолчанию): мок-бэкенд в памяти (`src/api/mock.ts`) с теми же вызовами и формами ответов, что в `contracts/api.md`. Токен не сохраняется, при перезагрузке снова экран входа. В чат можно написать слово `!ошибка`, чтобы показать экран ошибки ИИ.
- `VITE_USE_MOCKS=false`: запросы идут на `/api/*`. Vite проксирует `/api` на `http://localhost:8000` (бэкенд Ильи). Другой адрес: `VITE_API_URL=https://...`. Токен хранится в `localStorage`.

## Структура
- `src/api`: клиент (`client.ts`: токен, таймауты, ошибки, 401), мок (`mock.ts`), единая точка `api` (`index.ts`).
- `src/phone`: рамка iPhone и кабинет. `CabinetContext.tsx` держит сессию, план, чат. Экраны: вход и регистрация, онбординг, чат со списком диалогов, план, финансы, профиль.
- `src/landing`: презентация слева (`Slides.tsx`), шапка и управление автопоказом (`Landing.tsx`), шейдерный фон.
- `src/phone/demo.ts` и `Director` в `phone/Cabinet.tsx`: сцены автопоказа.
- `src/data/alfaProducts.ts`: продукты Альфа-Банка, все цифры в одном файле. Перед защитой сверить с alfabank.ru/sme.
- `src/types/plan.ts`: типы повторяют `/contracts/schemas`.

## Ошибки в интерфейсе
`401 UNAUTHORIZED` возвращает на вход с пояснением. Сеть и таймаут (15 с, для ответа ИИ 35 с) показываются в чате с кнопкой «Повторить». Остальные коды показывают `message` из ответа бэкенда как есть.

## Автопоказ
Телефон справа показывает сцену, соответствующую слайду слева: вход, пустой чат, диалог с ИИ (печатается сам, шаги слева подсвечиваются по ходу), план (сам прокручивается к шагам и рискам), кредит (к продуктам банка), профиль, итоговый чат.

- Данные берутся из заготовок (`mocks/data.ts`), к бэкенду автопоказ **не обращается** и сессий не создаёт, в том числе с `VITE_USE_MOCKS=false`.
- Сцена переключается, когда прокрутка слайдов остановилась (220 мс), поэтому при быстром скролле ничего не мелькает.
- Как только человек коснулся телефона, автопоказ выключается, телефон остаётся у него. Вернуть можно переключателем в шапке (с настоящим бэкендом он выходит из аккаунта) или кнопкой «Попробовать самому» в начале.
- Если есть сохранённый вход (настоящая сессия), автопоказ не включается.
- На экранах уже, чем 1024 px, автопоказ отключён: телефон лежит над слайдами и не закреплён.
- Прокрутка внутри телефона не передаётся странице (`overscroll-contain`), а чат прокручивает только свой список. Не используйте `scrollIntoView` внутри телефона: он двигает и страницу.
