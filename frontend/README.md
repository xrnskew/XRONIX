# Frontend

React + Vite + TypeScript + Tailwind v4 + react-router + Recharts.

```
cd frontend
npm install
npm run dev      # http://localhost:5173
npm run build
```

- `VITE_USE_MOCKS=true` (по умолчанию): диалог и данные берутся из `src/mocks`.
- `src/landing`: презентация слева. `src/phone`: рамка iPhone и кабинет (чат, план, финансы, профиль).
- `src/types/plan.ts`: черновик типов по разделам 5.2–5.3, после согласования переедет в `/contracts`.
