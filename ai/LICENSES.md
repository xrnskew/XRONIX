# Лицензии: данные, инструменты, история с моделью

Обновлено 21 октября 2026 года (раунд 3). Это инженерная записка, не юридическое заключение.

## Итог

Сервис `ai` — **собственная экспертная система на правилах**: словари, правила, разбор чисел и два файла данных. Нейросети, внешних API и ключей в проверяемой версии нет, во время работы сервис в сеть не ходит.

| Что | Источник | Лицензия | Где лежит |
|---|---|---|---|
| Число заведений по сферам в городах | OpenStreetMap через Overpass API | **ODbL 1.0**, в ответах — «по данным OpenStreetMap» | `app/rules/data/knowledge.cities.json`, сырые ответы `knowledge/raw/osm/` |
| Средняя зарплата по региону | Росстат, «Среднемесячная номинальная начисленная заработная плата … по субъектам РФ» (`tab4-zpl-2025.xlsx`), 2025 год | открытые данные, со ссылкой на источник | то же, файл Росстата в `knowledge/raw/rosstat/` |
| Население и регион города | справочник городов [arbaev/russia-cities](https://github.com/arbaev/russia-cities), 2023 | факты, без охраняемого текста | `frontend/src/data/cities.json` → база |
| Банк фраз | сгенерирован GigaChat-2-Max через API при разработке, вычитан людьми | права на сгенерированный текст — у клиента (п. 1.11, 6.2 соглашения) | `app/rules/data/phrases.json`, промпт и сырые ответы `knowledge/` |
| Словари и шаблоны | наши (`contracts/`) | — | снимок в `app/rules/data/` |

Чего **нет**: Авито, ЦИАН, 2ГИС, Яндекс Карт и других сайтов, условия которых запрещают сбор. Факты языковой моделью не генерировались: GigaChat писал только формулировки, а числа подставляются из базы.

## 1. OpenStreetMap (ODbL 1.0)

- Источник: https://www.openstreetmap.org/copyright. Данные — © участники OpenStreetMap, лицензия Open Database License 1.0.
- Что берём: только **число** объектов с тегами сферы внутри административной границы города (Overpass `out count`). Сами объекты, координаты и названия не сохраняем.
- Обязательства ODbL: ссылка на источник есть в каждой фразе с фактом («по данным OpenStreetMap»), в `sources` базы и в `THIRD_PARTY_NOTICES.md`. Производная база (`knowledge.cities.json`) распространяется на тех же условиях.
- Нагрузка на Overpass: пауза 5 с между запросами, повтор при 429/5xx с растущей паузой, кеш сырых ответов (`knowledge/raw/osm/overpass.json`). Повторная сборка `--offline` в сеть не ходит.
- Данные OSM неполные, поэтому в тексте только «около N», а меньше 10 объектов не называем совсем. Постаматы (`amenity=parcel_locker`) считаются отдельно и в «пункты выдачи» не входят.

## 2. Росстат

- Страница: https://rosstat.gov.ru/labor_market_employment_salaries, файл `tab4-zpl-2025.xlsx` (лист «с 2018»), последний полный год — 2025.
- Официальная статистика публикуется для свободного использования со ссылкой на источник. В ответах — «по данным Росстата».
- Для городов Тюменской и Архангельской областей берётся строка «без автономных округов»: в округах зарплаты северные.
- Сайт Росстата использует сертификаты Минцифры, они лежат в `knowledge/certs/` и нужны только сборщику, в образ не входят.

## 3. GigaChat — инструмент генерации фраз

Источники:
- Соглашение об использовании сервиса GigaChat для физических лиц, редакция 6 февраля 2026: https://developers.sber.ru/docs/ru/policies/gigachat-agreement/individuals
- Политика допустимого использования, редакция 10 декабря 2025: https://developers.sber.ru/docs/ru/policies/gigachat-agreement/permissible-use-ai

Как используем:
- Только **при разработке**: `knowledge/generate_phrases.py` (свои `requirements.txt`, в образ не входит) генерирует варианты формулировок. Промпт — `knowledge/phrases_prompt.md`, сырые ответы — `knowledge/raw/gigachat/`.
- Ключ — от Саши, с призовыми пакетами токенов хакатона, только в переменной `GIGACHAT_AUTH_KEY`. В код, логи, файлы и отчёт не попадает.
- **п. 1.11, 6.2 соглашения:** исключительное право на сгенерированный контент принадлежит клиенту.
- **п. 2.4 соглашения:** ограничение «только личные некоммерческие цели» относится к режиму Freemium. Ключ с оплаченными пакетами под это ограничение не попадает. Коммерческое использование ИИ-сервиса по п. 6.2 политики — по отдельному соглашению. Для хакатона это не нужно; при выходе в продукт банку стоит заключить договор или заменить фразы своими.
- Каждый вариант прошёл автоматическую проверку (`knowledge/phrase_rules.py`, правила `checkPhrases` из `contracts/check.mjs` и `contracts/ai.md`) и вычитку людьми: в `phrases.json` поле `generated.reviewed_by`.

## 4. История: своя модель (отменённый план)

В раундах 1–2 планировалась своя нейросеть: LoRA-дообучение **Qwen3-1.7B** (Apache 2.0) на нашем датасете, генерация перефразов открытой GigaChat 3 Lightning (MIT). Датасет (`dataset/`) собран программно из шаблонов, без вызовов внешних моделей.

После раунда 2 Илья отменил обучение: правиловая система прошла пороги раздела 13.3 `docs/CONVEYOR.md` без модели. **Qwen и дообучение — не текущая реализация**, веса не обучались и в репозитории их нет. Датасет остаётся: по нему оцениваются правила.

## 5. Библиотеки

- Сервис: `fastapi`, `uvicorn` (BSD), `pydantic` (MIT).
- Только при разработке: `pymorphy3` и `pymorphy3-dicts-ru` (MIT; словари на основе OpenCorpora, CC BY-SA) — падежи городов в снимке; `num2words` (LGPL) — генератор датасета; `jsonschema` (MIT); `openpyxl` (MIT) — файл Росстата; `gigachat` (MIT) — генератор фраз. В образ сервиса они не входят.
